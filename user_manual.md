## Installing P2Ping -- Windows Only 
A Windows machine is needed to run this program.

Refer to INSTALL.md for instructions on isntalling this program on your machine.
For ease of access, you can create a shortcut to P2Ping.exe by right clicking on it, selecting "Show more options", then selecting "Send to" and then selecting desktop which will create a desktop shortcut for the file.


**Note:** P2Ping requires an IPv6 connection to run properly. You can check if you are using an IPv6 connection [here](https://test-ipv6.com/). If you do not have an IPv6 connection through your current network, you will have to switch to another network that has IPv6 allowed (i.e. mobile hotspot) in order to use P2Ping in its current state.


## Using P2Ping to commuicate with others
1. Click on the "Connect to Peers" button on the top right corner of the screen.
2. First decide on a local connection (if on the same wifi) or a public connection (across networks).
3. Next take the IP address listed and send it to your peer who is ready to connect to your device. Have your peer do the same on their end and send you their IP address.
4. Paste their IP address in the text box and hit enter.
5. A chat should open up and you can send messages and files to each other directly.
6. Simply exit the program when you are finished messaging each other. You can also end the connection with the red "End Connection" button and start a new one with a different peer if desired. 

**NOTICE:** Encrypting files and messages is still a work in progess. Currently messages are not saved. Any messages will be deleted when the application is terminated or when you hit the "clear messages" button.
