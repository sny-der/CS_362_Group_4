**P2Ping is currently only configured to run on Windows machines using an IPv6 or IPv6 capable connection.**
The source code for this app can be downloaded by cloning this repository. The app can be built using the command `pyinstaller P2Ping.spec`, which requires python and pyiinstaller. Pillow and customtkinter are required libraries for this app, and are not included in this repository. They can be installed using `pip install Pillow` and `pip install customtkinter` which requires Python and pip to be installed. P2Ping.spec can be reconfigured to suit any future work or additions, but must include contest_pybridge.exe unless it is replaced.
